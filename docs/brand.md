# Brand assets

Kut's distributable vector assets are in [assets](assets/):

- [Primary logo](assets/kut-logo.svg): the complete logo on a dark surface;
  use it for the README and other dark backgrounds.
- [Mark](assets/kut-mark.svg): for compact interfaces, favicon-like uses, and
  constrained spaces.

The core palette is turquoise <code>#2DD4BF</code>, amber <code>#FFB454</code>,
deep navy <code>#0B0F14</code>, and utility gray <code>#8AA0B4</code>.

The supplied design file is not a production asset. It is kept as a source of
layout and variant reference in [design/kut-logo-reference](design/kut-logo-reference/).
Use the standalone SVG files in <code>assets/</code>, rather than the reference
runtime files, in applications.
